# Security

This project is an unmaintained experiment and receives no security updates. Do not run it in production or with real accounts and data you cannot afford to expose. Vulnerability reports will not be triaged or fixed.

There is no OS sandbox: approved shell commands and local MCP servers run with the host user's permissions.

---

Este projeto é um experimento sem manutenção e não recebe correções de segurança. Não use em produção nem com contas e dados reais que você não possa expor. Relatos de vulnerabilidade não serão triados nem corrigidos.

Não há sandbox do sistema operacional: comandos de shell aprovados e servidores MCP locais rodam com as permissões do usuário do host.
